## Proyectos

### Books Scraper

Scraper que extrae todos los libros de books.toscrape.com

**Qué hace:**

- Extrae 1000 libros de 50 páginas automáticamente
- Filtra por precio máximo
- Exporta los resultados a CSV

**Tecnologías:**

- Python
- Requests
- BeautifulSoup4

**Cómo usar:**

1. Instala las dependencias: `pip install requests beautifulsoup4`
2. Ejecuta: `python scraper2.py`
3. Introduce el precio máximo cuando lo pida
